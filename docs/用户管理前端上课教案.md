> **配套材料**  
> - 学生阅读：**第 0 章基础必知** → `docs/用户管理前端CRUD全流程.md`  
> - 学生动手：同上文档第 1 章起（按接口逐步实现）  
> - 后端配套：`backend-server/docs/用户管理CRUD全流程.md`  
> - 源码参考：`src/pages/users/*`、`src/scripts/pages/users/list.ts`、`src/templates/pages/users/list.html`  
> - 建议课时：**3 学时**（第 1 节基础 60min + 第 2～3 节 CRUD 120min），或压缩为 2 学时（基础 25min + CRUD 95min）

## 零、基础与技术选型（建议第 1 节或 CRUD 课前 25～40 分钟）

> **目标：** 学生能说出「为什么用 TS / Vite / Alpine」「四个目录各干什么」，再写用户接口不会懵。  
> **材料：** 投屏 `src/` 目录树 + `docs/用户管理前端CRUD全流程.md` 第 0 章。

### 0.1 开场：前端在整体里干什么（3 min）

**话术：**

> 后端 Spring Boot 已经提供了 URL 和 JSON，前端不做业务规则，只做三件事：  
> **① 长页面 ② 用户点了发请求 ③ 把返回的 JSON 显示出来。**  
> 今天用的不是 Vue，是 **TypeScript + HTML + Alpine**，方便对照后端分层，少一层框架黑盒。

### 0.2 技术栈板书（10 min）

| 技术 | 一句话 | 为什么不用别的 |
|------|--------|----------------|
| TypeScript | 给 JSON 字段起类型名 | 少拼错字段；和 Swagger 一一对应 |
| Vite | 启动 dev、打包、代理 `/api` | 快；开发时避免 CORS |
| Alpine | `x-model` / `x-text` 绑定数据 | 比 jQuery 省事；比 Vue 轻 |
| Navigo | `#/users` 换页 | 单页应用不整页刷新 |
| Shoelace | 按钮、对话框 | 统一 UI |
| apiClient | 封装 fetch + token | 全站请求写法一致 |

**强调：** 本课 **不教 Vue/React**，不是不会，是教学顺序先 REST 再框架。

### 0.3 目录架构图（10 min，必画）

```
core/        → 路由、登录、HTTP（全站一份）
pages/users/ → model + api + list.page.ts（业务数据与接口）
scripts/     → list.ts（Alpine 状态与按钮逻辑）
templates/   → list.html（表格和表单长什么样）
```

**让学生打开 IDE 对照走一遍：**

1. `main.ts` → `app.ts` → `initRouter()`  
2. `routes.ts` 里 `/users` 指向哪个 `list.page.ts`  
3. `list.page.ts` 加载哪个 `list.html`  
4. `list.html` 的 `x-data` 对应哪个 `list.ts`  

**对照后端（有 Java 基础的学生）：**

> model ≈ DTO，api ≈ Controller 地址，list.ts ≈ Service+页面编排，templates ≈ 视图。

### 0.4 TypeScript 迷你课（10 min，只讲本仓库出现的）

在投屏 `users.model.ts` / `users.api.ts` 上边讲边指：

| 语法 | 指给学生看 |
|------|------------|
| `interface UserVO` | Swagger UserResponse |
| `export` / `import` | 文件之间怎么引用 |
| `async` / `await` | `loadData` 里等接口 |
| `Promise<ApiResult<T>>` | 为什么要 `if (!res.ok)` |
| `PageResponse<UserVO>` | 列表 records 的类型 |
| `?` 可选字段 | email 可以不传 |
| `type DialogMode = 'create' \| 'edit'` | 弹窗模式 |

**不要展开：** 泛型原理、装饰器、namespace——够用即可。

### 0.5 Alpine 迷你课（5 min）

打开 `templates/pages/users/list.html`：

- `x-data="userListComponent()"` → 数据从哪来  
- `x-model="form.username"` → 表单  
- `@click="submitForm()"` → 事件  
- **预警：** `template x-if` 只能一个根节点，否则密码框消失（后面创建用户再强调）

### 0.6 请求链路演示（5 min）

1. 登录 admin  
2. F12 → Network → 点用户管理  
3. 指 `GET /api/users`、Request Headers 里的 `Authorization`  
4. 指 vite 代理：浏览器只访问 5173，不会直连 8080  

### 0.7 基础节小结（1 min 提问）

- TS 在本项目主要干什么？→ **描述接口 JSON**  
- `users.api.ts` 和 `list.ts` 分工？→ **api 发请求，list 管页面状态和按钮**  
- 为什么要 `apiClient`？→ **统一带 token、统一错误格式**

## 四、讲授要点（话术参考）

### 4.1 开场

> 后端已经提供了 5 个 REST 接口，前端要做的是：**在网页上发同样的 HTTP 请求，把 JSON 显示出来**。  
> 我们不写 Java，写的是 TypeScript + HTML；请求用 `fetch` 封装在 `apiClient` 里。

### 4.2 分层图（必画）

```
list.html（长什么样）
    ↑ 数据绑定
list.ts（什么时候调接口、表单状态）
    ↑
users.api.ts（5 个函数，对应 5 个 URL）
    ↑
apiClient（加 token、处理 401）
    ↑
/users → 后端
```

对比后端：**Controller ≈ users.api，Service ≈ list.ts 里的业务判断，Entity ≈ UserVO**。

### 4.3 每个接口的教学节奏（固定模板）

1. **Swagger Execute** → 投屏 JSON  
2. **指字段** → 在 model 或 api 里写类型/拆包  
3. **写一行 api 方法** → 在 list.ts 里调用  
4. **补 HTML** → 浏览器点一下  
5. **失败案例**（401、400 用户名重复）→ 看 Network Response  

### 4.4 两个必讲坑

**坑 1：Alpine `template x-if` 多根节点**

- 现象：创建弹窗只有用户名，没有密码  
- 原因：一个 template 里两个并列 div  
- 解决：外包一层 div 或改用 `x-show`  

**坑 2：confirm 不弹窗**

- 现象：点禁用无任何反应  
- 原因：用了未挂载 DOM 的 Alpine 对象  
- 解决：`import { confirm } from '@/core/ui/components/ConfirmDialog'`  

### 4.5 与后端响应差异（板书）

| 接口 | 后端 JSON 特点 | 前端处理 |
|------|----------------|----------|
| GET /users | 直接 PageResponse | `res.data.records` |
| GET /users/{id} | 包在 `user` 里 | `res.data.user` |
| POST /users | `userId` + `user` | 一般用 `res.data.user` |
| PUT | 同 GET 详情 | `res.data.user` |
| DELETE | `userId` + message | 只需判断 `res.ok` |

## 七、常见问题速查

| 学生问题 | 答复要点 |
|----------|----------|
| 401 | 先登录；看 Authorization 头 |
| 403 | 必须 admin 角色 |
| 400 密码不能为空 | 创建表单缺 password 或没传到 API |
| 创建了但列表没有 | 看 POST 是否 200；是否 refresh |
| CORS | 应用 vite 代理，不要直连 8080 |
| 改了 html 没效果 | 改的是 templates 不是 pages 下旧 html |

## 九、基础部分常见学生问题

| 问题 | 答复 |
|------|------|
| 不会 TS 能学吗？ | 先会 interface + async/await 即可，边做边查第 0.4 节 |
| 和 Vue 有什么区别？ | Vue 把 HTML/JS/CSS 包在 .vue；我们是分开文件，思路类似「数据驱动视图」 |
| 为啥 HTML 在 templates 不在 pages？ | 约定：pages 放 TS，templates 放纯 HTML，方便 loadAndRender |
| `@/` 是什么？ | 代表 `src/`，避免 `../../../` |
| 改了 pages 下 list.page.html 没效果？ | 真正用的是 `templates/pages/users/list.html` |
